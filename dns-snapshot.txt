중요 : www 와 ai 는 프록시가 꺼져 있다 (Cloudflare 회색 구름 / DNS only)

Cloudflare 는 주소만 알려주고, 실제 접속은 클라우드타입으로 곧장 간다.
www.opennegolab.com 의 응답에 Cloudflare 표시(server: cloudflare, cf-ray)가
없는 것으로 확인했다.

새 Cloudflare 계정에 도메인을 추가하면 레코드가 주황 구름(Proxied)으로
들어온다. www 와 ai 는 반드시 회색(DNS only)으로 바꿔야 지금과 같이 동작한다.
www 없는 주소(opennegolab.com)만 주황 구름이어야 한다 — 넘겨주기를
Cloudflare 가 해 주기 때문이다.

되찾는 방법 (Cloudflare 를 못 쓰게 됐을 때)
  1. 닷네임코리아(dotname.co.kr) 에 로그인한다 — 도메인 소유자 계정이다
  2. 네임서버를 새 DNS 로 바꾼다 (새 Cloudflare 계정이든 다른 곳이든)
  3. 위 레코드를 그대로 다시 넣는다
  4. www 없는 주소의 넘겨주기를 다시 만든다
     - Cloudflare 라면 : opennegolab.com 에 프록시(주황) A 레코드를 하나 두고,
       Rules -> Redirect Rules 에서 https://www.opennegolab.com 으로 301,
       경로와 쿼리 유지
     - Cloudflare 가 아니라면 : 그 DNS 업체의 넘겨주기(포워딩) 기능을 쓴다
  * 네임서버를 바꾸면 퍼지는 데 최대 하루 걸린다. 그동안 사이트가 끊길 수 있다
